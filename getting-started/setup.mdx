Esta guía te lleva paso a paso por la instalación de todas las herramientas necesarias para desarrollar Stewart en tu equipo. Al final tendrás el proyecto abierto en Godot 4 y listo para ejecutar.

## Requerimientos

Antes de comenzar, asegúrate de tener acceso a las siguientes herramientas:

| Herramienta | Uso |
|---|---|
| Godot 4 (versión más reciente) | Motor del juego |
| Git + GitHub | Control de versiones |
| Editor de código | Edición de scripts GDScript o C# |
| Notion | Documentación interna del equipo |
| Pixieditor u otro programa de dibujo | Arte y sprites |
| FL Studio u otro editor de audio | Música y efectos de sonido |

<Info>
  El acceso al grupo del proyecto en Notion y GitHub es gestionado por el equipo. Contacta a un miembro del Stewart DevTeam si no tienes acceso.
</Info>

## Configurar el entorno

<Steps>
  <Step title="Instalar Godot 4">
    Descarga la versión más reciente de Godot 4 desde el sitio oficial:

    - **Godot 4 (GDScript):** versión estándar, recomendada para la mayoría de contribuidores.
    - **Godot 4 (C#):** versión opcional con soporte para .NET. Requiere tener instalado el SDK de .NET.

    <Note>
      El proyecto usa Godot **4.6** con el renderizador **Forward Plus**. Asegúrate de usar esta versión o una compatible para evitar advertencias de migración al abrir el proyecto.
    </Note>
  </Step>

  <Step title="Clonar el repositorio">
    Clona el repositorio oficial desde GitHub:

    ```bash terminal
    git clone https://github.com/Stewart-DevTeam-Team/stewart_prealpha.git
    cd stewart_prealpha
    ```

    Si prefieres una interfaz gráfica, puedes clonar el repositorio directamente desde **GitHub Desktop** usando la opción *File → Clone repository*.
  </Step>

  <Step title="Abrir el proyecto en Godot">
    1. Abre Godot 4.
    2. En el **Project Manager**, selecciona **Import**.
    3. Navega hasta la carpeta donde clonaste el repositorio.
    4. Selecciona el archivo `project.godot` y confirma la importación.

    Godot importará los recursos automáticamente. Este proceso puede tomar unos segundos la primera vez.

    <Info>
      La resolución del viewport del proyecto es **1440 × 810**. Si tu pantalla tiene una resolución diferente, Godot ajustará la vista automáticamente.
    </Info>
  </Step>

  <Step title="Ejecutar el proyecto">
    Con el proyecto abierto en Godot, presiona **F5** o haz clic en el botón **Play** (▶) en la barra superior para ejecutar el juego desde la escena principal.

    Si todo está configurado correctamente, el juego iniciará sin errores en la consola de Godot.
  </Step>
</Steps>

<Note>
  Si encuentras errores de importación o recursos faltantes al abrir el proyecto por primera vez, cierra y vuelve a abrir Godot. La reimportación automática resuelve la mayoría de estos problemas.
</Note>
